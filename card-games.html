AI Card Game Projects

I enjoy exploring how artificial intelligence can learn to play games. These projects use card games to experiment with learning strategies and decision-making.

Blackjack with Reinforcement Learning

I built a Blackjack project in which an AI learns how to play using reinforcement learning. By playing hands and receiving feedback on its outcomes, it can improve its choices over time.

This project gave me a way to explore how an agent learns a strategy through experience in a game with uncertain outcomes.

Go Fish AI

I’m currently working on a Go Fish game where an AI can learn to play. The project explores how an agent can make decisions and develop a strategy as it plays.

This is a work in progress, and I’m continuing to build out the game and learning approach.
